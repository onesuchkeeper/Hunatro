Hunatro

A resource pack for Balatro that changes textures, voice lines and dialogue to be HuniePop themed.

Features:

  • 24 Deck Skins
  • 84 Jokers
  • 30 Blinds (Dates)
  • 4 Seals
  • 4 Suits
  • 7 Deck Backs
  • 2 Vouchers
  • 3 Tarots
  • 2 Planet
  • 1 Spectral
  • 1 Enhancement

Installation

Hunatro is available via the Balatro Mod Manager

For manual installation, once Steamodded is installed place the unzipped Hunatro folder in AppData/Roaming/Balatro/Mods. See Steamodded for futher installation guidance. The latest version of Hunatro requires Steamodded version 1.0.0~ALPHA-1030f or greater.
